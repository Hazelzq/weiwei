# 游园灯
本仓库是 **Carousel Lamp · 旋转木马相片灯**（作者：咕噜蛋Daria）的**修改版本**，仅用于非商业的向朋友展示。原作的署名与许可说明见网站最后一页（`credits.html`）和 [LICENSE](LICENSE)。

## 与原作相比的修改
- 改为纯静态网页（HTML + CSS + JS），不需要服务器和构建步骤，可以直接用 GitHub Pages 托管。
- 旋转木马固定为夜晚、旋转、起风的状态，删去了对应的三个按钮。
- 封面不再显示署名，署名与致谢单独放在最后一页
- 地图页三张图分别来自 Sony 产品图和两位小红书用户（@momo、@橘子手作）的照片，署名已写在最后一页。
